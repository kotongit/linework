# Linework

A macOS app for gesture drawing and a 38-week daily practice plan, with s.e.a., your synthetic empathetic ally, along the way. By hyprsea solutions.

## Install

Linework needs macOS 27 or later on a Mac with Apple silicon.

1. Open `Linework-2.0.dmg` and drag Linework onto Applications.
2. Open Linework. macOS won't open it the first time, because the app isn't signed with a paid Apple certificate. Click Done.
3. Open System Settings > Privacy & Security, scroll to Security and click **Open Anyway** next to Linework.

After an update, macOS may ask again for access to the folder holding your library.

## Your library

Everything you make lives in a normal folder you choose, like an Obsidian vault. The app itself holds nothing of yours, so you can back up, move or rename the folder, and reinstalling the app loses nothing except preferences such as your name and clock format.

```
Linework Library/
  library.json        Marks the folder as a library
  Photos/             Your reference photos
  Drawings/           Photos of benchmark attempts
  Canvases/           One folder per Freehand canvas
  Progress/           Readable text files: photos, benchmarks, sets, presets, plan, checks, sessions
```

- Photos you add, rename or remove in Finder are picked up when you come back to the app.
- Deleting inside the app moves files to the Trash.
- A library can sit in a synced folder such as iCloud Drive, but don't open it on two Macs at the same time.
- File > Open Library switches to another library.

## Building

```bash
swift test
scripts/build-app.sh
scripts/make-dmg.sh
```

These need only Xcode's command line tools. There are no third-party dependencies.

To sign with a Developer ID later, set `LINEWORK_SIGN_IDENTITY` before running the scripts. Notarization then goes in `scripts/make-dmg.sh`.

### Development

Debug builds have tools that must run against a scratch folder, and they refuse to run without one:

```bash
LINEWORK_LIBRARY=/tmp/scratch .build/debug/Linework --library-checks <images>
LINEWORK_LIBRARY=/tmp/scratch .build/debug/Linework --snapshots <output folder> <images>
LINEWORK_LIBRARY=/tmp/scratch .build/debug/Linework --print-counts
LINEWORK_LIBRARY=/tmp/scratch .build/debug/Linework --perf <image>
```

`LINEWORK_TODAY=yyyy-MM-dd` pretends it's another day, and `LINEWORK_FONT_DIR` loads fonts outside the app bundle.

The plan's text is generated by `scripts/generate-plan.py` from a PDF that isn't in this repo. `scripts/plan-rewrites.json` keeps calendar dates out of it.

`scripts/import-gesturedrawing.py` brings data over from the old GestureDrawing app, one time only.
