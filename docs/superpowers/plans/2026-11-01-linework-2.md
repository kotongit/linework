# Linework 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Linework in this repo as a clean version 2.0 whose data lives in a user-visible library folder, with a week-and-weekday plan, named canvases and a `.dmg` installer.

**Architecture:** Source moves from `../GestureDrawing` piece by piece. New file formats and decisions go in `LineworkCore` under tests. An `@Observable` `LibraryStore` then replaces SwiftData one section at a time, and SwiftData is deleted last, so the app builds and runs after every task.

**Tech Stack:** Swift 6 (tools 6.2), Swift Package Manager, SwiftUI, AppKit, Foundation, ImageIO, Core Image, Core Text, Vision, CryptoKit. Python 3 for dev scripts only.

**Spec:** `docs/superpowers/specs/2026-11-01-linework-2-design.md`

## Global Constraints

- Bundle ID `com.hyprsea.linework`, app `Linework.app`, version 2.0 in one place, macOS 27 minimum, Apple silicon.
- No third-party code, no private APIs, no SwiftData or Xcode project in the final result.
- `GestureDrawing` appears nowhere in code, app or library, except `scripts/import-gesturedrawing.py`.
- `../GestureDrawing` and `~/Library/Application Support/GestureDrawing` are read-only. Never write to or delete them.
- Debug runs always set `LINEWORK_LIBRARY` to a scratch folder. Never run a debug build against a real library.
- All JSON is indented with sorted keys and ISO 8601 dates, and every file carries `version`.
- Plan text and copy never name a calendar date. Follow s.e.a.'s existing voice: lowercase `s.e.a.` with periods.
- Commit after each task. Never add attribution lines. Don't push until Task 16.
- Don't change how anything looks except as the spec's §10 lists.

## Review Focus

1. **The library disappears while the app is open** (drive unplugged, folder trashed). Expect: a failed save is reported, nothing is recreated at the old path, and data in memory isn't discarded. Test in Task 8.
2. **Identical copies of one photo in `Photos/`** (same hash, two names). Expect: a missing entry adopts one file only, and the other becomes a new photo. Test in Task 6.
3. **Canvas rename differing only in case or Unicode form** ("hands" to "Hands", NFC against NFD "é"), on a case-insensitive disk. Expect: a case-only rename succeeds, and true duplicates are refused. Test in Task 7.
4. **Time zone or daylight-saving change.** Expect: week and weekday mapping and "counts toward" days stay correct, because they use calendar days rather than elapsed seconds. Test in Task 3.
5. **Folder that can't be written** (read-only or permission denied) chosen as a library. Expect: a clear message, with no half-made library left behind. Test in Task 5.
